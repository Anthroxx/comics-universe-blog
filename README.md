# Proyecto Tienda de Cómics - "Comics Universe"

Este proyecto es una practica de sitio web comercial desarrollado en HTML, CSS y JavaScript para una tienda de cómics llamada Comics Universe.

# Estructura del Proyecto

El sitio web sigue un esquema de navegación:

tienda-comics/
├── index.html             # Formulario de inicio de sesión
├── main.html              # Página principal
├── marvel.html            # Catálogo específico de cómics de Marvel
├── manga.html             # Catálogo específico de Manga
├── README.md              # Este archivo
└── assets/
    ├── css/
    │   └── styles.css     # Estilos globales y específicos del sitio
    ├── js/
    │   ├── main.js        # Lógica de interacciones generales
    │   └── login.js       # Validación de credenciales de inicio de sesión
    └── img/
        ├── header.jpg     # Imagen principal 
        ├── marvel.jpg     # Imagen para Marvel
        ├── manga.jpg      # Imagen para Manga
        ├── spiderman.jpg  # Portada de Spider-Man
        ├── civil_war.jpg  # Portada de Civil War
        ├── daredevil.jpg  # Portada de Daredevil
        ├── guantelete.jpg # Portada de Guantelete
        ├── one_piece.jpg  # Portada de One Piece
        ├── demon_slayer.jpg # Portada de Demon Slayer
        ├── berserk.jpg    # Portada de Berserk
        └── chainsaw_man.jpg # Portada de Chainsaw Man
